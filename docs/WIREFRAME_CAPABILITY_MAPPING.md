# Nightfall Wireframe-to-Real-Implementation Capability Matrix

Nightfall enforces a strict **zero fake, mocked, or hardcoded runtime implementation** policy (`packages/mock-fixtures` has been deleted from the monorepo). Every metric, table row, Sankey flow, diff, campaign step, HTTP/WebSocket trace, sandbox run, and Git branch/commit rendered in the UI is backed by durable `node:sqlite` (`WAL`) state and live runtime execution.
